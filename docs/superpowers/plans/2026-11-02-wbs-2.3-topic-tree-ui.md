# WBS 2.3 Topic Tree UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the interactive Topic Tree UI for `/syllabus`, allowing students to browse chapters per course, toggle `TODO`/`DOING`/`DONE` statuses with instant optimistic progress bar updates, and rollback safely on API errors.

**Architecture:** A top horizontal course switcher (`CourseTabs`), a real-time `MasteryHeaderCard` computing completion metrics and grade flow, a vertical staggered list of `TopicCard` components with 3-state chips, and an `AddTopicModal` for manual chapter creation, backed by an optimistic-update state hook and GSAP micro-animations.

**Tech Stack:** React 19, Tailwind CSS v4, GSAP 3 (`@gsap/react`), React Router 7, Vitest & React Testing Library.

**Spec:** [docs/superpowers/specs/2026-11-02-wbs-2.3-topic-tree-ui-design.md](file:///d:/Study/Web%20Application%20Development/SFSH/docs/superpowers/specs/2026-11-02-wbs-2.3-topic-tree-ui-design.md)

## Global Constraints
- Acceptance criterion: "Switching TODO/DOING/DONE updates the progress bar immediately and rolls back if the API fails."
- Design system: Urbanist typography, Luma Green palette (`#243100`, `#DBEF90`), dark/light mode compatible.
- Bilingual localization: 100% translatable in English (default) and Vietnamese via `useLanguage()`.
- Rule 06 compliance: Queries and updates are user-scoped.
- Zero layout thrashing: GSAP animations use transforms and opacity; no heavy multi-layer blur filters.

## Review Focus
1. Rapid clicking on multiple topic chips in quick succession preserves correct cumulative progress calculations.
2. Network failure during status change immediately reverts chip and progress bar to previous state and displays a readable rollback toast.
3. Switching courses cleanly resets and animates the new course's topic tree without residual inline styles.
4. Adding a new topic immediately positions it at the end of the chapter list with sequential chapter numbering.
5. Empty course state (course without any syllabus topics) renders an informative empty state with a "Add First Topic" button.
